Collaborative + Content-based Filtering

Movie Recommendation System

Pick a movie you like, or rate a few, and get recommendations. It runs live in your browser using the same logic as the Python project.

View code on GitHub

Content-based: finds movies with the most similar genres.


Hybrid: rate a few movies you have seen (leave the rest as "–"). Collaborative filtering and genre similarity are blended.

How it works

Content-based
Each movie becomes a genre vector (TF-IDF). Movies whose vectors point the same way are similar.
Collaborative
Movies liked by the same people are similar. Your ratings are compared to those patterns to predict what you'd rate others.
Hybrid
60% collaborative score + 40% genre similarity to the movies you rated 4 or 5.

Demo data: 40 real movies and ratings from 60 simulated users, so suggestions are illustrative only. Swap in MovieLens data in the Python project for real results.
